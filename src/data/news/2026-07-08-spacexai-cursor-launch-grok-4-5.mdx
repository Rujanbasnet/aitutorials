SpaceXAI and Cursor have [publicly launched Grok 4.5](https://x.ai/news/grok-4-5), the first AI model built jointly since SpaceX acquired Cursor in a deal valuing the coding startup at $60 billion. After weeks in [private beta at SpaceX and Tesla](/news/2026-06-29-xai-grok-4-5-private-beta-spacex-tesla/), the model is now available to everyone.

## What Makes Grok 4.5 Different

This isn't a general-purpose chatbot. Grok 4.5 is a mixture-of-experts model trained on trillions of tokens of real Cursor user interactions — actual coding sessions, debugging workflows, and software development tasks. Cursor CEO Michael Truell says the model was trained from scratch on Colossus, xAI's supercomputer.

The result is a model built specifically for working across large codebases. It can generate production-ready code, debug software, plan development tasks, and handle multi-step coding workflows. SpaceXAI also expanded its capabilities into legal analysis and financial document processing, positioning it as a professional tool rather than a consumer chatbot.

SpaceXAI claims [roughly 2x the token efficiency](https://www.bloomberg.com/news/articles/2026-07-08/spacexai-cursor-unveil-grok-ai-model-for-legal-finance-tasks) of comparable frontier models, meaning it can solve tasks in under half the number of steps. Elon Musk calls it "Opus-class but cheaper."

## Pricing and Availability

Grok 4.5 is available today in three places: directly within [Cursor](https://cursor.com/blog/grok-4-5) on all subscription plans, in Grok Build (SpaceXAI's developer platform), and through the SpaceXAI API console.

Pricing undercuts the competition at $2 per million input tokens and $6 per million output tokens. A faster premium tier runs $4/$18. For comparison, [Claude Opus](/blog/claude-code-vs-cursor/) and GPT-5 class models typically cost significantly more per token.

The model is not yet available in the EU due to regulatory considerations.

## What This Means for You

If you use Cursor for coding, Grok 4.5 is now another model option alongside [Claude](/tutorials/what-is-claude-ai/) and GPT. The tight integration with Cursor's editor — combined with training data from millions of real coding sessions — could give it an edge for day-to-day development work.

For developers choosing between AI coding tools, this launch signals that the [coding AI race](/blog/claude-code-vs-cursor/) is accelerating fast. The SpaceX-Cursor combination now has the compute power, the user data, and a competitive model to challenge Anthropic and OpenAI directly.
