Anthropic has added three new capabilities to Claude Managed Agents that could change how businesses use AI for complex, long-running work. The headline feature — called "dreaming" — lets AI agents review their own past sessions, spot patterns, and get better at their jobs over time.

## What's New

**Dreaming** is the most novel addition. It works as a scheduled background process that reviews an agent's completed sessions, extracts useful patterns, and updates the agent's memory. Think of it like an employee reflecting on their week and writing down what they learned. You can let dreaming update memory automatically, or review every change before it takes effect.

In practice, this means a Claude agent handling customer support tickets could notice it keeps making the same type of mistake and correct itself — without a developer manually rewriting the prompt.

**Outcomes** give developers a way to define what "good enough" looks like. You write a rubric, and a separate grader checks the agent's output against it. If the work falls short, the agent revises. In Anthropic's internal testing, this improved task success by up to 10 percentage points, with the biggest gains on harder problems. File generation quality also jumped — 8.4% better for Word documents and 10.1% better for PowerPoint files.

**Multiagent orchestration** lets a lead agent split a complex job into pieces and hand each one to a specialist sub-agent. Each sub-agent can run a different model, use different tools, and work in parallel on a shared filesystem. Everything stays traceable through the Claude Console.

## What This Means for You

If you use Claude for repetitive or multi-step work — research, content creation, data processing, coding — these features make agents noticeably more reliable. Dreaming is especially significant because it introduces a form of continuous improvement that doesn't require constant human tuning.

Outcomes and multiagent orchestration are available now in public beta. Dreaming is in research preview, so you can try it, but expect rough edges. All three features are part of [Claude Managed Agents](https://9to5mac.com/2026/05/07/anthropic-updates-claude-managed-agents-with-three-new-features/), Anthropic's platform for deploying persistent AI agents.

For anyone building AI workflows in a business setting, this is worth paying attention to. Self-improving agents that can coordinate with each other represent a meaningful step beyond single-prompt chatbots.
